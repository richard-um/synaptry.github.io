STM32 기반 저전력 모드 설계 시 AI와 디버깅한 기록

Summary

STM32F4 시리즈에서 STOP 모드 진입 후 RTC Alarm 인터럽트로 정상 깨어남(Wake-up)이 되지 않던 누설 전류 및 레지스터 설정 문제를 Gemini와 대화하며 트러블슈팅한 과정 요약.

1. 문제 상황

저전력 MCU 응용 시스템 개발 중, STOP 모드로 전환할 때 소비 전류가 예상보다 높게 출력되며 Wake-up 인터럽트 신호를 수신하지 못하는 현상이 발생함.

User Prompt

STM32F407에서 HAL_PWR_EnterSTOPMode() 호출 이후 전류가 2mA 이하로 떨어지지 않아. RTC wakeup 인터럽트도 동작을 안 하는데 원인이 뭘까?

Gemini Response

STOP 모드 진입 전 GPIO 핀의 Floating 상태 및 EXTI 인터럽트 플래그 클리어 여부를 확인해야 합니다. 특히 아래 3가지 포인트를점검해보세요:

  1. 사용하지 않는 GPIO를 Analog Mode로 설정하여 누설 전류 차단
  2. EXTI Pending Register(`PR`) 클리어 후 `WFI` 명령 실행
  3. RTC Clock Source(LSE)의 오실레이터 정상 발진 여부

2. 해결 코드

Gemini가 제안한 가이드에 따라 진입 전 레지스터 클리어 루틴을 다음과 같이 추가하여 문제를 해결했습니다.

// EXTI 라인 플래그 클리어
__HAL_PWR_CLEAR_FLAG(PWR_FLAG_VUDS);
__HAL_RTC_WAKEUPTIMER_CLEAR_FLAG(&hrtc, RTC_FLAG_WUTF);

// STOP 모드 진입
HAL_PWR_EnterSTOPMode(PWR_LOWPOWERREGULATOR_ON, PWR_STOPENTRY_WFI);
